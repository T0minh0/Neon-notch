# Support

For help using Neon Notch, first check the [installation](docs/installation.md) and [troubleshooting](docs/troubleshooting.md) guides.

For reproducible bugs or feature requests, open an actionable GitHub issue with your macOS version, Xcode version, Neon Notch version or commit, expected and actual behavior, and safe reproduction steps. Do not attach agent transcripts, clipboard contents, credentials, or screenshots containing sensitive information. GitHub issues are the support channel, and there is no guaranteed response time.

Please report security vulnerabilities through the process in [SECURITY.md](SECURITY.md), not through public issues.
