# Contributing

Thanks for helping improve Neon Notch. Before opening a pull request, discuss substantial changes in an issue so the scope and macOS behavior are clear.

Keep changes focused, preserve the local-first privacy model, and add or update tests when behavior changes. Run the canonical test command in [README](README.md#testing) before submitting. For visual changes, update the relevant tracked design evidence and [design QA guide](docs/design-qa.md) when appropriate.

Do not include credentials, personal paths, private logs, or screenshots containing sensitive desktop content. By contributing, you agree that your contribution is licensed under the [MIT License](LICENSE).
